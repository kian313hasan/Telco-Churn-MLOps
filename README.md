# 📊 پروژه پایپ‌لاین جامع MLOps برای پیش‌بینی ریزش مشتریان (Telco Churn)

**دانشگاه بین‌المللی امام خمینی (ره) - درس یادگیری ماشین** **استاد :** دکتر باحقیقت  
**دانشجو:** حسن حمزه  

---

## 🌐 ۱. معرفی پروژه (Project Overview)
هدف این پروژه، طراحی و پیاده‌سازی یک پایپ‌لاین استاندارد، ماژولار و قابل تکرار (End-to-End MLOps Pipeline) برای پیش‌بینی ریزش مشتریان (Churn) با استفاده از دیتاست **Telco Customer Churn (IBM Dataset)** است.  
در این پروژه، مدیریت نسخه‌های داده (Data Versioning از v1 تا v3) در پوشه‌های مجزا، آموزش همزمان و ارزیابی ۴ مدل یادگیری ماشین، ردیابی کامل آزمایش‌ها با MLflow و در نهایت استقرار سرویس با استفاده از Docker پیاده‌سازی شده است.

---

## 🏗️ ساختار پوشه‌بندی پروژه / Project Structure
پیاده‌سازی پروژه کاملاً مطابق با ساختار پوشه‌بندی استاندارد خواسته شده انجام شده است:

```text
project/
├── data/
│   ├── v1/          # داده‌های خام / Raw IBM Dataset (Excel/CSV)
│   ├── v2/          # داده‌های پاک‌سازی شده / Cleaned & Encoded Data
│   └── v3/          # مهندسی ویژگی‌ها و نرمال‌سازی / Feature Engineered Data
├── src/
│   ├── data_loader.py    # بارگذاری داده‌ها / Data Loading
│   ├── preprocessing.py  # پاک‌سازی و رفع مقادیر خالی / Cleaning & Encoding
│   ├── features.py       # ساخت ویژگی‌های جدید و مقیاس‌دهی / Feature Engineering
│   ├── train.py          # آموزش مدل‌های چهارگانه / Model Training
│   ├── evaluate.py       # ارزیابی مدل و ماتریس آشفتگی / Evaluation & Metrics Log
│   └── mlflow_utils.py   # ابزارهای مدیریت آزمایش‌ها / MLflow Helpers
├── mlruns/               # لاگ‌ها و آرتیفکت‌های ام‌ال‌فلو / MLflow Local Database
├── run_pipeline.py       # اجرای خودکار کل فرآیند / Automated Pipeline Execution
├── app.py                # سرویس وب پیش‌بینی / FastAPI Web Service
├── Dockerfile            # کانتینری‌سازی سرویس / Docker Configuration
└── README.md             # مستندات پروژه / Project Documentation


 ۱. معرفی پروژه
هدف این پروژه طراحی و پیاده‌سازی یک پایپ‌لاین استاندارد و ماژولار MLOps برای پیش‌بینی ریزش مشتریان (Churn) با استفاده از دیتاست Telco Customer Churn (IBM Dataset) است. در این پروژه، داده‌ها به صورت ساخت‌یافته مدیریت شده و چندین مدل یادگیری ماشین آموزش و ارزیابی می‌شوند. تمامی آزمایش‌ها، پارامترها و نتایج در MLflow ثبت خواهند شد تا قابلیت ردیابی فراهم شود. در نهایت مدل منتخب در قالب یک سرویس قابل استقرار با استفاده از Docker ارائه می‌شود.


۲. نحوه نصب
برای راه‌اندازی محیط پروژه و نصب تمامی کتابخانه‌ها و وابستگی‌های پیش‌فرض، دستور زیر را در ترمینال خود اجرا کنید:
pip install -r requirements.txt


۳. اجرای Pipeline
کل چرخه حیات پروژه از بارگذاری داده تا ثبت نتایج نهایی در فایل اصلی run_pipeline.py خودکارسازی شده است. با اجرای این فایل، مراحل زیر به صورت متوالی و زنجیره‌ای انجام می‌شوند:

بارگذاری داده‌ها (v1): بارگذاری نسخه خام دیتاست بدون تغییر.

پاک‌سازی داده‌ها (v2): حذف ستون‌های غیرضروری، رفع مقادیر خالی (Missing Values) و تبدیل داده‌های تصنیفی به عددی (Encoding).

مهندسی ویژگی‌ها (v3): ساخت ویژگی‌های جدید و نرمال‌سازی داده‌های عددی با StandardScaler.

برای اجرای کامل پایپ‌لاین خودکار دستور زیر را وارد کنید:
python run_pipeline.py


۴. آموزش مدل
فرآیند آموزش در سکریپت src/train.py با بهره‌گیری از Stratified 5-Fold Cross Validation برای جلوگیری از Overfitting و تضمین ثبات نتایج انجام می‌گیرد. تمامی مراحل با seed=42 ثابت اجرا می‌شوند تا نتایج کاملاً قابل تکرار باشند. چهار مدل زیر به صورت مستقل روی نسخه‌های مختلف داده آموزش داده می‌شوند:

Logistic Regression (تنظیم‌شده با max_iter=5000)

Random Forest Classifier

XGBoost Classifier

CatBoost Classifier

برای هر مدل معیارهای ارزیابی (Accuracy, Precision, Recall, F1-score, ROC-AUC) به همراه پارامترها و نمودار ماتریس آشفتگی (Confusion Matrix) در MLflow ذخیره می‌شود. جهت مشاهده داشبورد ارزیابی دستور زیر را بزنید:
mlflow ui


۵. استقرار و نحوه استفاده از سرویس
آخرین و بهترین مدل آموزش دیده روی آخرین نسخه دیتاست از MLflow دریافت شده و در قالب یک وب سرویس با FastAPI (app.py) کانتینری‌سازی شده است.

ساخت تصویر داکر (Docker Build):
docker build -t telco-churn-mlops:v1 .

اجرای کانتینر سرویس (Docker Run):
docker run -d -p 8000:8000 telco-churn-mlops:v1
نحوه استفاده از سرویس (Inference API):
پس از اجرا، وب سرویس روی پورت 8000 فعال خواهد بود. تست سلامت سرویس از آدرس زیر قابل دسترسی است:
http://localhost:8000/

برای ارسال داده‌های مشتری و دریافت پیش‌بینی ریزش، درخواست خود را به صورت POST به همراه ساختار JSON ورودی به نقطه پایان (Endpoint) زیر ارسال کنید:
http://localhost:8000/predict
